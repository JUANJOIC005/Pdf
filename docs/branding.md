# Identidad visual

Los paquetes de Pdf usan el identificador de escritorio `io.github.juanjoic005.pdf`. Sus recursos Linux están en `assets/app-icon/hicolor/` y se copian al paquete por `packaging/linux/package.sh`.

El icono es el diseño original y abierto de PdfCraft, restaurado desde upstream. No se incluyen ni se imitan iconos de Adobe; las fuentes, licencia y hashes se registran en `ATTRIBUTION.toml`.
