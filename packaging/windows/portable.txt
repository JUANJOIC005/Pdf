Pdf portable mode

While this file sits next to Pdf.exe, Pdf keeps its settings, log files, crash-recovery
autosaves and new digital IDs in the PdfData folder beside it, and writes nothing to
%APPDATA% or %LOCALAPPDATA%. Copy the whole folder to move Pdf with its settings.

Delete this file to use the normal per-user folders (%APPDATA%\Pdf and
%LOCALAPPDATA%\Pdf) instead. If PdfData can't be written (for example on a read-only
drive), Pdf says so and uses the per-user folders instead.
